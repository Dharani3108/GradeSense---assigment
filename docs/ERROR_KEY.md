# Error key — sample student answer

The sample answer is at [`backend/docs/samples/student-answer.pdf`](../backend/docs/samples/student-answer.pdf)
and is generated by [`backend/scripts/make-student-answer.ts`](../backend/scripts/make-student-answer.ts)
(`npm run seed:answer`), so the mistakes below are reproducible rather than hand-typed.

It is written as a plausible mid-range paper for the supplied question paper: some points are fully
correct, some are half-made, several state the opposite of the model answer, and a handful of words
are misspelled the way a scan or a rushed student would produce them.

Every mistake below is deliberate. The right-hand column is what the grader actually returned on the
current build — the run that produced [`example-annotated-answer.pdf`](./example-annotated-answer.pdf).

**Result: 4.5 / 15 (30%), flagged for human review.**

## Q1 — Science (2.5 / 5)

| # | Intended mistake | Correct version | Rubric point | Graded |
|---|---|---|---|---|
| 1 | — (written correctly) | Battery, switch, bulb, resistor in a closed series loop | q1-c1 | **1/1 correct** |
| 2 | "The voltmeeter is also connected **in series** with the bulb" | A voltmeter is connected **in parallel across the bulb**, because it measures potential difference across it | q1-c2 | **0/1 incorrect** |
| 3 | — (written correctly) | Current flow and the function of each component | q1-c3 | **1/1 correct** |
| 4 | "If the resistence is increased then the current **will also increase**, because a bigger resistance pushes more current" | If resistance increases and voltage is constant, current **decreases** (V = IR) | q1-c4 | **0/1 incorrect** |
| 5 | No diagram, no component labels, no current direction — only "(diagram drawn on the rough sheet)" | A labelled diagram showing conventional current direction | q1-c5 | **0.5/1 partial** |

Mistakes 2 and 4 are the important ones: both use every word the rubric expects, so a grader that
only matches keywords awards full marks for them. See
[`backend/src/utils/polarity.ts`](../backend/src/utils/polarity.ts).

## Spelling errors

All five are flagged as `spelling` annotations with the correction shown beside the word.

| Written | Correct |
|---|---|
| curent | current |
| potentiel | potential |
| voltmeeter | voltmeter |
| resistence | resistance |
| equilibrum | equilibrium |

The detector is deliberately conservative — it needs a single unambiguous candidate that is not just
another inflection of the same word — because a wrong "did you mean" on a correctly spelled word
costs more trust than a missed typo. On this paper it produces these five and no false positives.
